Instructions from Alan Feltz (December 6, 2024):

ROOT version installed to use PyROOT:
root-6.32.06

ROOT directory:
/usr/local/root-6.32.06

Set the following environment variables to use PyROOT.

RootDir=/usr/local/root-6.32.06

export PATH=${RootDir}/bin:$PATH
export PYTHONPATH=${RootDir}/lib
export LD_LIBRARY_PATH=${RootDir}/lib
